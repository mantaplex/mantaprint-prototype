Panduan Koneksi & Pengaturan Klien

Panduan langkah demi langkah menghubungkan laptop dan perangkat ke printer.

Hubungkan Printer Anda Terlebih Dahulu

HeykPrint Hub mendukung berbagai merk dan tipe printer. Panduan spesifik untuk perangkat Anda akan otomatis muncul di sini begitu kabel USB printer dicolokkan.

1 Colokkan USB

Sambungkan kabel USB printer ke salah satu port USB pada STB.

2 Nyalakan Printer

Nyalakan saklar power printer dan pastikan kertas tersedia.

3 Panduan Otomatis

Sistem akan langsung mengenali printer dan menampilkan instruksinya di sini.

Koneksi Chromebook (Zero Driver)

Printer telah dibagikan melalui IPP Everywhere. Chromebook Anda akan langsung mendeteksi printer tanpa perlu instalasi driver.

Metode 1: Otomatis (Rekomendasi) 10 Detik
  1. 1 Pastikan Chromebook terhubung ke WiFi kantor yang sama.
  2. 2 Buka Settings → Device → Print and scan → Printers.
  3. 3
    Di bawah daftar "Available printers to save", klik tombol Save di samping printer:
    Printer @ HeykPrint
  4. 4 Selesai! Tekan Ctrl + P untuk mulai mencetak.
Metode 2: Tambah Manual Jika mDNS disekat

Gunakan cara ini jika printer tidak otomatis muncul:

  1. 1 Di menu Printers Chromebook, klik tombol Add Printer (+).
  2. 2
    Masukkan detail antrean berikut:
    Name: Printer
    Address:
    192.0.2.10:631
    Protocol: IPP
    Queue:
    printers/printer
  3. 3 Klik tombol Add. Selesai!

Koneksi dari Apple macOS

Mendukung Apple AirPrint Driverless & IPP Everywhere. Tersedia 3 cara mudah menghubungkan:

Cara 1 • Otomatis (AirPrint) Paling Mudah (Tanpa Install Driver Apapun)
  1. 1 Buka System Settings (Pengaturan Sistem) → Printers & Scanners.
  2. 2 Klik Add Printer, Scanner, or Fax... (+).
  3. 3
    Di tab Default (ikon printer), printer otomatis terdeteksi:
    Canon G3030 series @ HeykPrint AirPrint
  4. 4 Klik tombol Add. Selesai!

Apple iPhone & iPad (AirPrint)

Tanpa aplikasi tambahan apapun:

  1. 1. Hubungkan iPhone/iPad ke WiFi kantor yang sama.
  2. 2. Buka file → tekan Share → pilih Print.
  3. 3. Pilih printer yang muncul, lalu tekan Print.
Android Smartphone & Tablet

Menggunakan Default Print Service bawaan Android:

  1. 1. Buka Settings → Connected devices → Printing.
  2. 2. Pastikan Default Print Service berstatus ON.
  3. 3. Buka file → Cetak (Print) → Printer HeykPrint akan otomatis terdeteksi.
